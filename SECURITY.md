# Security policy

Report vulnerabilities in the Crewbo IDE privately through the main repository's private vulnerability reporting: https://github.com/crewbo/crewbo/security/advisories/new

Do not open a public issue. Vulnerabilities in Code OSS itself belong to [Microsoft's vscode project](https://github.com/microsoft/vscode/security/policy); in VSCodium's build scripts, to [VSCodium](https://github.com/VSCodium/vscodium).

The IDE is a preview (`v0.x`): only the latest release receives fixes.
